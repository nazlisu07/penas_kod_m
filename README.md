# 🎮 Pena's Kod Mutfağı — Browser Games Collection

A collection of browser games and interactive experiences I built from scratch with **HTML, CSS and vanilla JavaScript** — no game engines, no frameworks.

Sıfırdan, sadece HTML/CSS/JavaScript ile yazdığım tarayıcı oyunları ve interaktif deneyimler.

### ▶️ [Play now / Hemen oyna](https://nazlisu07.github.io/penas_kod_m/)

## Games / Oyunlar

| Game | Description |
|---|---|
| **[Maniyeah](https://nazlisu07.github.io/penas_kod_m/Maniyeah/)** | Platformer with 6 playable characters, power-ups (shield, speed, gravity), enemies and music |
| **[ManiFight](https://nazlisu07.github.io/penas_kod_m/manifight/)** | Fighting game |
| **[Pixel Defense: Neon Warfare](https://nazlisu07.github.io/penas_kod_m/savunma/)** | Tower-defense style shooter with neon visuals |
| **[Neon Yılan Pro Max](https://nazlisu07.github.io/penas_kod_m/yilan/)** | Modern take on the classic Snake |
| **[Kızıl Dava: 1980](https://nazlisu07.github.io/penas_kod_m/dedektif/)** | Detective mystery — solve an unsolved murder |
| **[Project: Mnemosyne](https://nazlisu07.github.io/penas_kod_m/dedektif_pro/)** | Advanced detective / mystery game |
| **[Karanlık Oda](https://nazlisu07.github.io/penas_kod_m/karanlik/)** | Dark-room escape experience |
| **[Mistik Kahin](https://nazlisu07.github.io/penas_kod_m/kahin/)** | Interactive fortune-teller with music |
| **[Zaman Kapsülü](https://nazlisu07.github.io/penas_kod_m/kapsul/)** | Write a message to your future self |
| **[Dijital Kum Sanatı](https://nazlisu07.github.io/penas_kod_m/kum/)** | Falling-sand physics art simulation |

## Tech

- HTML5 Canvas & DOM-based rendering
- Vanilla JavaScript (game loops, collision detection, physics, state management)
- CSS animations
- Hosted on GitHub Pages
